AOCL-ScaLAPACK library for AMD - Release Notes - version 5.2.0
------------------------------------------------------------------------------------

AOCL-ScaLAPACK, or Scalable LAPACK, is a library of high performance linear algebra
routines for distributed memory computers supporting MPI.

AMD optimized AOCL-ScaLAPACK depends on following 3 libraries for build and executing
tests
•	AOCL-BLIS
•	AOCL-libFLAME
•	An MPI library. In our experiments, we have validated with OpenMPI library

AOCL-ScaLAPACK for AMD is the optimized version of ScaLAPACK for AMD EPYC and AMD
Ryzen processor families.

Highlights of AMD optimized AOCL-ScaLAPACK 5.2.0
------------------------------------------------------------------------------------
- Enhancements
    - AOCL-ScaLAPACK spec upgrade to Netlib ScaLAPACK 2.2.2
    - C wrapper interface for AOCL-ScaLAPACK computational and Auxiliary APIs (SRC and TOOLS)
    - Minor bug fixes and test-suite enhancements with new tests for PDORGQR factorization and PDSTEDC APIs
    
Please refer AOCL User Guide for supported Operating Systems and Compilers.

The package contains AMD AOCL-ScaLAPACK Library binaries which use AOCL-BLIS,
AOCL-libFLAME optimized for the AMD EPYC and AMD Ryzen processor families.
