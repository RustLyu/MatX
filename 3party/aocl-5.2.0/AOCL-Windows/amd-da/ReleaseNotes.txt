AOCL DA - Release Notes - AOCL version 5.2.0
---------------------------------------------------
 
AOCL DA Contents
--------------------
AOCL-DA is a data analytics library providing optimized building blocks for data analysis. It is written with a C-compatible interface to make it as seamless as possible to integrate with the library from whichever programming language you are using. This intended workflow for using the library is as follows:
-- load data from memory by reading CSV files or using the in-built da_datastore object
-- preprocess the data by removing missing values, standardizing, and selecting certain subsets of the data, before extracting contiguous arrays of data from the da_datastore objects
-- data processing (e.g. principal component analysis or linear model fitting)
 
Highlights of AOCL-DA 5.2.0:
--------------------------------------------

AOCL-Data Analytics is a new data analytics library providing optimized building blocks for data analysis and classical machine learning.
-	Key functionality:
  -	Loading data from memory by reading CSV files.
  -	Pre-processing data by removing missing values, standardizing, and selecting subsets of data.
  -	Processing data (using, for example, principal component analysis, linear models, etc.)
-	Options to call AOCL-Data Analytics:
  -	C-compatible interface to enable seamless integration with multiple programming languages.
  -	C++ overloads for increased data abstraction.
  -	Python API.
  -	scikit-learn patch to enable existing scikit-learn users to benefit from the performance of AOCL- Data Analytics with minimal code changes.
- What’s new in release 5.2
  -	Python wheels for Windows
  -	Python APIs now accept all array-like inputs including Pandas data frames
  -	New APIs for train_test_split and pairwise distances
  -	Addition of Ball tree and k-d tree options for DBSCAN clustering and k-nearest neighbors
  -	Performance improvements to support vector machines, decision forests, DBSCAN, k-means clustering, linear models, and k-nearest neighbors


Please refer AOCL User Guide for supported Operating Systems and Compilers. 

The package contains AOCL-DA libraries, binaries and header files that are built with optimizations for AMD EPYC and Ryzen Processor family.
